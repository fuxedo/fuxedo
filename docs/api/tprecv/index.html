Synopsis

#include <atmi.h>

int tprecv(int cd, char **data, long *len, long flags, long *event);

Description

tprecv() waits for the next message on a conversation and stores it in *data (a tpalloc() buffer, resized as needed). When what arrives is not data but a protocol event, the call fails with TPEEVENT and *event says which: TPEV_SENDONLY (the peer handed send permission over), TPEV_DISCONIMM (the peer disconnected), TPEV_SVCSUCC / TPEV_SVCFAIL (the service returned).

Arguments

ArgumentDescription
cdConversation descriptor from tpconnect().
data, lenBuffer pointer and returned message length.
flagsSee below.
eventReceives event bits when the call fails with TPEEVENT.

Flags

FlagDescription
TPNOBLOCKFail with TPEBLOCK immediately when no message is ready.
TPNOTIMEWait without a deadline.
TPSIGRSTRTRestart interrupted waits.
TPNOCHANGEForce the incoming buffer type to match the buffer passed in.

Errors (tperrno)

CodeDescription
TPEBADDESCcd is not an open conversation.
TPEEVENTAn event arrived; check *event.
TPEBLOCKTPNOBLOCK was set and nothing is ready.
TPETIMEThe wait exceeded the conversation timeout.
TPESYSTEM, TPEOSPlatform or operating system failure.

Example

Full source: docs/api/examples/conv.c (build and run with make -C docs/api/examples check TUXDIR=<install>); the lines documenting tprecv() are highlighted.

// tpconnect()/tpsend()/tprecv()/tpdiscon() example: a scripted
// conversation with the CHAT service. Connect data ("hello") is the
// first thing the service sees; the client ends with tpdiscon().

#include <stdio.h>
#include <string.h>
#include <atmi.h>

int main() {
  if (tpinit((TPINIT *)NULL) == -1) {
    perror("tpinit");
    return 1;
  }

  char *buf = tpalloc("STRING", NULL, 1024);
  strcpy(buf, "hello");
  long len = 0;
  long revent = 0;

  // a conversation is opened with an explicit direction: TPSENDONLY
  // (caller sends first) or TPRECVONLY (caller waits first); any
  // other flag word, including 0, fails with TPEINVAL
  int cd = tpconnect((char *)"CHAT", buf, 0, TPSENDONLY);
  if (cd == -1) {
    fprintf(stderr, "tpconnect failed: %s (%d)\n", tpstrerror(tperrno),
            tperrno);
    return 1;
  }

  // tpsend delivers one message; TPRECVONLY hands send permission to
  // the peer, which learns of it through TPEV_SENDONLY from tprecv
  strcpy(buf, "how are you?");
  if (tpsend(cd, buf, 0, TPRECVONLY, &revent) == -1) {
    fprintf(stderr, "tpsend failed: %s (%d)\n", tpstrerror(tperrno),
            tperrno);
    return 1;
  }

  // tprecv waits for one message or event; revent tells events from
  // data (TPEV_SENDONLY: the peer handed send permission over)
  if (tprecv(cd, &buf, &len, 0, &revent) == -1) {
    fprintf(stderr, "tprecv failed: %s (%d)\n", tpstrerror(tperrno),
            tperrno);
    return 1;
  }
  printf("service says: %s\n", buf);

  // tpdiscon tears the conversation down immediately; the service
  // sees TPEV_DISCONIMM from tprecv (a graceful end is an empty
  // message, which maps to the service's tpreturn)
  if (tpdiscon(cd) == -1) {
    fprintf(stderr, "tpdiscon failed: %s (%d)\n", tpstrerror(tperrno),
            tperrno);
    return 1;
  }

  tpfree(buf);
  tpterm();
  return 0;
}
