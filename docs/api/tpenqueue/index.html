Synopsis

#include <atmi.h>

int tpenqueue(char *qspace, char *qname, TPQCTL *ctl,
              char *data, long len, long flags);

Description

tpenqueue() appends the buffer data to the queue qname in queue space qspace. Queue spaces live in the device named by the QMCONFIG environment variable; when the application runs a TMQUEUE server for the space, the request is routed through it, otherwise the caller talks to the queue files directly.

The TPQCTL structure carries optional delivery properties; a zeroed structure means a plain, persistent message. The flags argument itself must be 0.

Inside a transaction the enqueue is staged with the transaction and is undone when the transaction aborts, so a message either appears exactly once or not at all.

Arguments

ArgumentDescription
qspace, qnameQueue space and queue names, both required. An unknown queue fails with TPENOENT.
ctlTPQCTL control structure. Zero all of it for plain delivery; see the flags below.
data, lenThe message buffer; len 0 for self-describing types (STRING, FML32, VIEW32) like in tpcall().
flagsMust be 0. Anything else fails with TPEINVAL.

Flags

FlagDescription
TPQREPLYQSet ctl.replyqueue to a queue name; the reply to this message is expected there.
TPQFAILUREQSet ctl.failurequeue for messages that fail delivery.
TPQTIME_ABS, TPQTIME_RELSet ctl.deq_time to the absolute epoch time, or seconds from now, when the message becomes visible. Until then tpdequeue() skips it; the MIB T_APPQMSG class still lists it as TIME-state.
TPQPRIORITYSet ctl.priority (0-100, default 50) for priority-ordered queues.
TPQCORRIDSet ctl.corrid, a caller-chosen correlation id, to find the message again with TPQGETBYCORRID on dequeue.
TPQMSGIDOn return, ctl.msgid identifies the stored message.

Errors (tperrno)

CodeDescription
TPEINVALNULL arguments, nonzero flags, or ctl field combinations that do not parse.
TPENOENTThe queue space or queue does not exist.
TPEDIAGNOSTICQueue manager rejection; ctl.diagnostic carries a QME_* code such as QMEBADQUEUE or QMEENOMSG.
TPETRANQueue operations were requested inside a transaction for a resource manager that cannot stage them.
TPETIME, TPESYSTEM, TPEOSTimeouts and internal failures.

Notes

Visibility. Messages with a future deq_time are not returned by tpdequeue() until their time arrives; an expired message moves to its failure queue automatically. The T_APPQMSG MIB class lists every stored message, future ones included.

Example

Full source: docs/api/examples/enqueue.c (build and run with make -C docs/api/examples check TUXDIR=<install>); the lines documenting tpenqueue() are highlighted.

// Enqueue example: tpenqueue() puts a message on a /Q queue.
// Queue files live in the device named by the QMCONFIG environment
// variable; the sample domain does not need a TMQUEUE server for
// this. run.sh creates the DOCS queue space and the TASKS queue
// before invoking this program.

#include <stdio.h>
#include <string.h>
#include <atmi.h>

static int fail(const char *what) {
  fprintf(stderr, "%s failed: %s (%d)\n", what, tpstrerror(tperrno),
          tperrno);
  return 1;
}

int main(void) {
  if (tpinit(NULL) == -1) {
    return fail("tpinit");
  }

  char *msg = tpalloc("STRING", NULL, 64);
  strcpy(msg, "urgent: ping");

  // TPQCTL describes optional delivery properties; zero means plain
  // delivery. TPQREPLYQ records a queue name with the message so a
  // reply can be routed there by whoever processes it.
  TPQCTL ctl;
  memset(&ctl, 0, sizeof(ctl));
  ctl.flags = TPQREPLYQ;
  strcpy(ctl.replyqueue, "PINGRPLY");

  // tpenqueue(qspace, queue, ctl, data, len, flags) appends the
  // buffer to the queue. Like tpcall(), STRING buffers pass len 0.
  // Inside a transaction the enqueue is staged with it and undone on
  // abort. On TPEDIAGNOSTIC, ctl.diagnostic carries a QME_* code.
  if (tpenqueue("DOCS", "TASKS", &ctl, msg, 0, 0) == -1) {
    fprintf(stderr, "tpenqueue failed: %s (%d) diagnostic %ld\n",
            tpstrerror(tperrno), tperrno, ctl.diagnostic);
    return 1;
  }

  printf("enqueued: %s\n", msg);
  tpfree(msg);
  tpterm();
  return 0;
}
