Synopsis

#include <atmi.h>

int tpdequeue(char *qspace, char *qname, TPQCTL *ctl,
              char **data, long *len, long flags);

Description

tpdequeue() removes the next visible message from qname and returns it in *data. *data must point at a tpalloc'd buffer; the library may replace it with a larger one if the message does not fit.

Messages whose deq_time lies in the future are skipped, so a queue holding only future messages behaves as empty. Waiting is governed by TPQWAIT in ctl->flags, with an optional deadline from TPQTIME_ABS/TPQTIME_REL; the flags argument itself accepts TPNOTIME (wait without a deadline) and the selectors below.

Arguments

ArgumentDescription
qspace, qnameQueue space and queue names, both required. An unknown queue fails with TPENOENT.
ctlTPQCTL control structure; zeroed for a plain dequeue.
data, lenAddress of the buffer pointer and a length. The buffer must come from tpalloc().
flags0, TPNOTIME, TPQPEEK, or a selector.

Flags

FlagDescription
TPQWAITctl.flags: wait for a message instead of failing with TPETIME on an empty queue.
TPQTIME_ABS, TPQTIME_RELctl.flags: with TPQWAIT, set ctl.deq_time as the wait deadline (absolute epoch or seconds).
TPNOTIMEflags: with TPQWAIT, wait without a deadline.
TPQGETBYMSGID, TPQGETBYCORRIDctl.flags with ctl.msgid or ctl.corrid set: take the specific message instead of the first one.
TPQPEEKRead the message without removing it.

Errors (tperrno)

CodeDescription
TPEINVALNULL arguments, *data not tpalloc'd, or invalid flag combinations.
TPENOENTThe queue space or queue does not exist.
TPETIMENo visible message (and no wait, or the wait deadline passed).
TPEDIAGNOSTICQueue manager rejection; ctl.diagnostic carries a QME_* code.
TPETRAN, TPESYSTEM, TPEOSTransactional misuse and internal failures.

Notes

Reply routing. A message enqueued with TPQREPLYQ names the queue where the service reply belongs; a TMQFORWARD-driven service chain reads the reply queue from the dequeued message.

Example

Full source: docs/api/examples/dequeue.c (build and run with make -C docs/api/examples check TUXDIR=<install>); the lines documenting tpdequeue() are highlighted.

// Dequeue example: tpdequeue() takes the next available message off
// a /Q queue. run.sh runs ./enqueue first so a message is waiting.

#include <stdio.h>
#include <string.h>
#include <atmi.h>

static int fail(const char *what) {
  fprintf(stderr, "%s failed: %s (%d)\n", what, tpstrerror(tperrno),
          tperrno);
  return 1;
}

int main(void) {
  if (tpinit(NULL) == -1) {
    return fail("tpinit");
  }

  char *msg = tpalloc("STRING", NULL, 64);
  long len = 64;

  // tpdequeue(qspace, queue, ctl, &data, &len, flags) removes the
  // next visible message and returns it in *data. Messages whose
  // deq_time lies in the future (TPQTIME_* at enqueue time) are
  // skipped, exactly like on the platform. ctl.flags TPQWAIT would
  // wait for a message instead of failing immediately.
  TPQCTL ctl;
  memset(&ctl, 0, sizeof(ctl));
  if (tpdequeue("DOCS", "TASKS", &ctl, &msg, &len, 0) == -1) {
    fprintf(stderr, "tpdequeue failed: %s (%d) diagnostic %ld\n",
            tpstrerror(tperrno), tperrno, ctl.diagnostic);
    return 1;
  }

  printf("dequeued: %s\n", msg);

  // the queue is empty now: without TPQWAIT the platform fails with
  // TPEDIAGNOSTIC and ctl.diagnostic QMENOMSG
  len = 64;
  int rc = tpdequeue("DOCS", "TASKS", &ctl, &msg, &len, 0);
  if (rc != -1 || tperrno != TPEDIAGNOSTIC || ctl.diagnostic != QMENOMSG) {
    fprintf(stderr, "expected TPEDIAGNOSTIC/QMENOMSG on an empty queue\n");
    return 1;
  }
  printf("empty queue dequeue failed with TPEDIAGNOSTIC/QMENOMSG\n");

  tpfree(msg);
  tpterm();
  return 0;
}
