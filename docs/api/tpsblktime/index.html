Synopsis

#include <atmi.h>

int tpsblktime(int blktime, long flags);

Description

tpsblktime() sets how long the thread's blocking calls wait before giving up with TPETIME. It applies to reply waits (tpcall() and tpgetrply()) and, on fuxedo, to queue waits as well. The value is a per-thread attribute, not a per-call one: TPBLK_NEXT is consumed by the next blocking call, TPBLK_ALL stays in effect until changed.

blktime 0 restores the platform default: wait forever is NOT the default: an unset timeout means the UBBCONFIG BLOCKTIME value applies (default about 60 seconds).

Units and granularity. flags carry the unit: TPBLK_SECOND everywhere, TPBLK_MILLISECOND on 12.x only (pinned: 22.1 rejects millisecond and microsecond units with TPEINVAL). Whatever the unit, the effective granularity on the platform is SCANUNIT: BLOCKTIME is a multiplier of the RESOURCES SCANUNIT parameter and the BBL scans for timed-out blocking calls once per SCANUNIT, which defaults to 10 seconds. Sub-SCANUNIT precision is not representable there. fuxedo's watchdog ticks once per second, so fuxedo honors second and millisecond blocktimes to roughly one second. That is tighter than the platform default and looser than a timer.

Arguments

ArgumentDescription
blktimeTimeout in the requested unit. 0 restores the UBBCONFIG default. Negative values fail with TPEINVAL.
flagsTarget (TPBLK_NEXT or TPBLK_ALL) OR unit (TPBLK_SECOND; TPBLK_MILLISECOND on 12.x). Other bits fail with TPEINVAL.

Flags

FlagDescription
TPBLK_NEXTApply to the next blocking call only.
TPBLK_ALLApply to all subsequent blocking calls on this thread.
TPBLK_SECONDblktime is in seconds.
TPBLK_MILLISECONDblktime is in milliseconds (12.x only; 22.1: TPEINVAL).

Exactly one target and one unit are required.

Errors (tperrno)

CodeDescription
TPEINVALNegative blktime, or a flags word that is not one target and one supported unit.

Notes

Version note (pinned). 12.x accepts TPBLK_MILLISECOND; 22.1 rejects TPBLK_MILLISECOND and TPBLK_MICROSECOND with TPEINVAL. fuxedo accepts both units.

12.2 vs 22.1

Millisecond/microsecond units: accepted on 12.x, rejected with TPEINVAL on 22.1.

Example

Full source: docs/api/examples/blktime.c (build and run with make -C docs/api/examples check TUXDIR=<install>); the lines documenting tpsblktime() are highlighted.

// tpsblktime()/tpgblktime() example: set a per-thread blocking
// timeout, read it back, and make a call that is subject to it.

#include <stdio.h>
#include <string.h>
#include <atmi.h>

int main() {
  if (tpinit((TPINIT *)NULL) == -1) {
    perror("tpinit");
    return 1;
  }

  char *buf = tpalloc("STRING", NULL, 32);
  strcpy(buf, "hello");
  long len = 32;

  // flags carry the target (TPBLK_ALL persists on the thread, TPBLK_NEXT
  // is consumed by the next blocking call) and the unit (TPBLK_SECOND;
  // 12.x also accepts TPBLK_MILLISECOND, 22.1 rejects it with TPEINVAL).
  // 0 restores waiting forever
  if (tpsblktime(5, TPBLK_ALL | TPBLK_SECOND) == -1) {
    fprintf(stderr, "tpsblktime failed: %s (%d)\n", tpstrerror(tperrno),
            tperrno);
    return 1;
  }

  // reads the timeout back in the requested unit; flags 0 means the
  // TPBLK_ALL value
  long ms = tpgblktime(TPBLK_MILLISECOND);
  printf("blocking timeout: %ld ms\n", ms);

  if (tpcall((char *)"TOUPPER", buf, 0, &buf, &len, 0) == -1) {
    fprintf(stderr, "tpcall failed: %s (%d)\n", tpstrerror(tperrno),
            tperrno);
    return 1;
  }

  printf("reply: %s\n", buf);
  tpfree(buf);
  tpterm();
  return 0;
}
