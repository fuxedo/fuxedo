Synopsis

#include <atmi.h>

int tpconnect(char *svc, char *data, long len, long flags);

Description

tpconnect() opens a conversation: a bidirectional, sequenced exchange with one service invocation, carried without the requester blocking in a service call. The service runs with TPCONV set in svcinfo->flags and reads the connect buffer from svcinfo->data; the two sides then trade messages with tpsend() and tprecv() until one of them ends it.

The conversation is half-duplex at any moment: exactly one side holds send permission, and handing it over is part of the protocol (TPRECVONLY on tpsend(), TPEV_SENDONLY events on tprecv()).

Arguments

ArgumentDescription
svcAdvertised service name; validated like tpcall().
data, lenOptional connect data, delivered to the service as svcinfo->data.
flagsAn explicit direction is mandatory, see below.

Flags

FlagDescription
TPSENDONLYThe caller sends first.
TPRECVONLYThe caller waits first.

Exactly one of the two mode bits must be set. Passing 0, both bits together, or any timing or call flag (TPNOBLOCK, TPNOTRAN, ...) fails with TPEINVAL - a direction is always spelled out.

Errors (tperrno)

CodeDescription
TPEINVALInvalid flag word or arguments.
TPENOENTNo server advertises svc.
TPETIMENo server accepted the connect within the timeout.
TPESYSTEM, TPEOSPlatform or operating system failure.

Notes

Ending it. Either side may end the conversation: tpreturn() from the service, or tpdiscon() from the caller. The peer learns of the end through TPEV_DISCONIMM, TPEV_SVCSUCC, or TPEV_SVCFAIL in revent, or a failed tpsend()/tprecv().

Example

Full source: docs/api/examples/conv.c (build and run with make -C docs/api/examples check TUXDIR=<install>); the lines documenting tpconnect() are highlighted.

// tpconnect()/tpsend()/tprecv()/tpdiscon() example: a scripted
// conversation with the CHAT service. Connect data ("hello") is the
// first thing the service sees; the client ends with tpdiscon().

#include <stdio.h>
#include <string.h>
#include <atmi.h>

int main() {
  if (tpinit((TPINIT *)NULL) == -1) {
    perror("tpinit");
    return 1;
  }

  char *buf = tpalloc("STRING", NULL, 1024);
  strcpy(buf, "hello");
  long len = 0;
  long revent = 0;

  // a conversation is opened with an explicit direction: TPSENDONLY
  // (caller sends first) or TPRECVONLY (caller waits first); any
  // other flag word, including 0, fails with TPEINVAL
  int cd = tpconnect((char *)"CHAT", buf, 0, TPSENDONLY);
  if (cd == -1) {
    fprintf(stderr, "tpconnect failed: %s (%d)\n", tpstrerror(tperrno),
            tperrno);
    return 1;
  }

  // tpsend delivers one message; TPRECVONLY hands send permission to
  // the peer, which learns of it through TPEV_SENDONLY from tprecv
  strcpy(buf, "how are you?");
  if (tpsend(cd, buf, 0, TPRECVONLY, &revent) == -1) {
    fprintf(stderr, "tpsend failed: %s (%d)\n", tpstrerror(tperrno),
            tperrno);
    return 1;
  }

  // tprecv waits for one message or event; an event arrives as -1 with
  // tperrno=TPEVENT and revent set (TPEV_SENDONLY: the peer handed send
  // permission over), the data riding with the event is still delivered
  int rc = tprecv(cd, &buf, &len, 0, &revent);
  if (rc == -1 && tperrno != TPEEVENT) {
    fprintf(stderr, "tprecv failed: %s (%d)\n", tpstrerror(tperrno),
            tperrno);
    return 1;
  }
  printf("service says: %s (revent=0x%lx)\n", buf, revent);

  // tpdiscon tears the conversation down immediately; the service
  // sees TPEV_DISCONIMM from tprecv (a graceful end is an empty
  // message, which maps to the service's tpreturn)
  if (tpdiscon(cd) == -1) {
    fprintf(stderr, "tpdiscon failed: %s (%d)\n", tpstrerror(tperrno),
            tperrno);
    return 1;
  }

  tpfree(buf);
  tpterm();
  return 0;
}
