Synopsis

#include <atmi.h>

long tptypes(char *ptr, char *type, char *subtype);

Description

tptypes() reports the type, subtype, and length of a tpalloc'd buffer. type and subtype receive NUL-terminated names (pass NULL to skip either); the return value is the buffer length in the type's units, or -1 with tperrno set on error.

Arguments

ArgumentDescription
ptrA buffer from tpalloc().
type, subtypeOutput buffers of at least 8 and 16 characters, or NULL.

Errors (tperrno)

CodeDescription
TPEINVALptr is not a typed buffer.

Example

Full source: docs/api/examples/buffers.c (build and run with make -C docs/api/examples check TUXDIR=<install>); the lines documenting tptypes() are highlighted.

// tpalloc()/tptypes()/tpfree() example: typed buffer lifecycle.

#include <stdio.h>
#include <string.h>
#include <atmi.h>

int main(void) {
  char *buf = tpalloc("STRING", NULL, 64);
  if (buf == NULL) {
    fprintf(stderr, "tpalloc failed: tperrno=%d\n", tperrno);
    return 1;
  }

  char type[8] = {0};
  char subtype[16] = {0};
  long len = tptypes(buf, type, subtype);
  if (len == -1) {
    fprintf(stderr, "tptypes failed: tperrno=%d\n", tperrno);
    tpfree(buf);
    return 1;
  }
  printf("type=%s subtype=%s len=%ld\n", type, subtype, len);

  strcpy(buf, "hello");

  tpfree(buf);
  return 0;
}
