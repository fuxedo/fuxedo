Synopsis

#include <atmi.h>

int tpsend(int cd, char *data, long len, long flags, long *revent);

Description

tpsend() delivers one message on a conversation opened with tpconnect(). The caller must hold send permission; sending without it fails with TPEPROTO. Each call carries at most one direction change, expressed with TPRECVONLY, after which the peer's tprecv() reports TPEV_SENDONLY.

Arguments

ArgumentDescription
cdConversation descriptor from tpconnect().
data, lenMessage buffer; len 0 uses the buffer length for self-describing types.
flagsSee below.
reventReceives event bits when the call fails with TPEEVENT.

Flags

FlagDescription
TPRECVONLYSend this message and hand send permission to the peer.
TPNOBLOCKFail with TPEBLOCK instead of waiting if the peer's queue is full.
TPNOTIMEWait without a deadline for queue space.
TPSIGRSTRTRestart interrupted waits.

Only the receive-side mode flip is accepted; TPSENDONLY makes no sense on a send and fails with TPEINVAL.

Errors (tperrno)

CodeDescription
TPEBADDESCcd is not an open conversation.
TPEPROTOThe caller does not hold send permission.
TPEEVENTA protocol event arrived; check *revent (TPEV_DISCONIMM, TPEV_SVCFAIL, ...).
TPEBLOCKTPNOBLOCK was set and the peer's queue is full.
TPESYSTEM, TPEOSPlatform or operating system failure.

Example

Full source: docs/api/examples/conv.c (build and run with make -C docs/api/examples check TUXDIR=<install>); the lines documenting tpsend() are highlighted.

// tpconnect()/tpsend()/tprecv()/tpdiscon() example: a scripted
// conversation with the CHAT service. Connect data ("hello") is the
// first thing the service sees; the client ends with tpdiscon().

#include <stdio.h>
#include <string.h>
#include <atmi.h>

int main() {
  if (tpinit((TPINIT *)NULL) == -1) {
    perror("tpinit");
    return 1;
  }

  char *buf = tpalloc("STRING", NULL, 1024);
  strcpy(buf, "hello");
  long len = 0;
  long revent = 0;

  // a conversation is opened with an explicit direction: TPSENDONLY
  // (caller sends first) or TPRECVONLY (caller waits first); any
  // other flag word, including 0, fails with TPEINVAL
  int cd = tpconnect((char *)"CHAT", buf, 0, TPSENDONLY);
  if (cd == -1) {
    fprintf(stderr, "tpconnect failed: %s (%d)\n", tpstrerror(tperrno),
            tperrno);
    return 1;
  }

  // tpsend delivers one message; TPRECVONLY hands send permission to
  // the peer, which learns of it through TPEV_SENDONLY from tprecv
  strcpy(buf, "how are you?");
  if (tpsend(cd, buf, 0, TPRECVONLY, &revent) == -1) {
    fprintf(stderr, "tpsend failed: %s (%d)\n", tpstrerror(tperrno),
            tperrno);
    return 1;
  }

  // tprecv waits for one message or event; revent tells events from
  // data (TPEV_SENDONLY: the peer handed send permission over)
  if (tprecv(cd, &buf, &len, 0, &revent) == -1) {
    fprintf(stderr, "tprecv failed: %s (%d)\n", tpstrerror(tperrno),
            tperrno);
    return 1;
  }
  printf("service says: %s\n", buf);

  // tpdiscon tears the conversation down immediately; the service
  // sees TPEV_DISCONIMM from tprecv (a graceful end is an empty
  // message, which maps to the service's tpreturn)
  if (tpdiscon(cd) == -1) {
    fprintf(stderr, "tpdiscon failed: %s (%d)\n", tpstrerror(tperrno),
            tperrno);
    return 1;
  }

  tpfree(buf);
  tpterm();
  return 0;
}
