This is the reference for the C API shared by Oracle Tuxedo and Fuxedo: the X/Open XATMI calls (tp*) and the FML32 fielded buffer calls (F*32). It is written for people who already program against the API and want exact flags, error codes, and edge behavior without page-filler.

Every page embeds a complete, compilable program from docs/api/examples, with the documented call highlighted; the whole app builds and runs with make -C docs/api/examples check TUXDIR=<install> against either Tuxedo or Fuxedo.

Conventions:

  • Error tables list the tperrno code and the condition that sets it. Only codes a real call can produce are listed.
  • A successful call does not reset tperrno; the value is meaningful only after -1. This matches Oracle Tuxedo behavior that production code depends on.
  • Where Oracle Tuxedo 12.2 and 22.1 differ, the difference is stated on the function's page; pages without such a note were cross-checked on both and behave the same.
  • Every page carries a compatibility line saying whether fuxedo implements the call and how it was verified.
