FAQ

Which license? MIT. Use it, modify it, ship it in commercial products; the text is in the repository's COPYING file. No copyleft, no per-CPU counting, no runtime license server.

Is this legal? What does Oracle think? Fuxedo is an independent implementation of the published X/Open XATMI specification plus the documented Oracle Tuxedo extensions. Interoperability constants (field ids, flag values, error codes, command names) are facts, not property. Oracle Tuxedo is a trademark of Oracle Corporation; Fuxedo is not affiliated with or endorsed by Oracle.

Is it production ready? For development and testing, yes, today. The compatibility suite runs against Oracle Tuxedo 12.2.2 and 22.1 in CI on every commit; the gap list on the status page is kept honest. For your production decision, run your own test suite against it: that is what it is built for.

What exactly differs from Oracle Tuxedo? Only what programs cannot observe: /Q stores messages as files in folders instead of a binary queue device, FML32 buffers skip the index section, wire bytes inside the IPC queues are Fuxedo's own. Everything an application or an administrator can see is pinned to the Oracle behavior, with one deliberate improvement: a busy system does not degrade under the one-second full-queue retry.

My Oracle_XA servers fail to boot with permission errors, but the database credentials are right. What is it? The LogDir in OPENINFO. The Oracle XA library opens a trace file there during xa_open, before any database work happens; if the server processes' user cannot write that directory, the open fails with permission-flavored errors that look like connect failures. Point LogDir at a directory the server user owns. The trace file itself, xa_NULL<date>.trc, is one per host and day, shared by every process, and is the first place to look when XA misbehaves - it logs every xa_start, xa_end, and recovery scan with return codes.

Which database grant does two-phase commit need? GRANT SELECT ON sys.dba_pending_transactions to the application user. Without it the transaction manager's recovery scan fails and prepared transactions stay in-doubt after a crash instead of being resolved. FORCE TRANSACTION is the companion privilege for heuristic resolution.

How do I migrate? Install side by side, build against Fuxedo headers, boot from the same UBBCONFIG, run your tests. The migration page has the full shape.
