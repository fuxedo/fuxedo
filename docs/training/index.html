Training

The person behind Fuxedo and the tuxedo-python bindings, Aivars Kalvans, teaches Tuxedo the way you need it in production: from the system calls up. Two decades of keeping C++ Tuxedo applications alive go into two or three days of hands-on work.

The emphasis is the Tuxedo good parts: the features real systems use, taught at the level of mechanics. Where the documentation says what a call does, the labs show what the process does: the msgrcv it blocks in, the shared memory it locks, the queue depth behind the latency spike. Sessions run on real booted domains; participants break things on purpose and learn to read the wreckage.

The promise that matters: what you learn in this course transfers 1:1, including to the only platform where your UBBCONFIG still loads.

Formats

FormatContent
